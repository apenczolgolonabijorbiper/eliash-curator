# eliash-curator
Eliash-curator gathers information and guides Golem14’s cognitive work in Chelm.

## First concept

Eliash is intended as an optional, reusable curator for applications built around
Golem. It helps gather and prepare information, preserve its origin, and turn
application goals into bounded collection and cognitive activities.

- **Curate information:** select, organize and deliver material with its context
  and limitations.
- **Guide cognitive work:** coordinate investigation, comparison, verification,
  deepening and follow-up within the application's authority.
- **Learn through use:** evolve shared methods, interfaces and routines from
  observed application needs.

The application defines purpose and permissions. Chelm owns durable runtime state
and publication; the Harness defines cognitive and memory rules; Shem or another
compatible cognizer performs the cognitive work.

## Direction of development

[Research Notebook](https://github.com/apenczolgolonabijorbiper/research-notebook)
will be the first application from which Eliash learns as it is implemented and
enhanced. Useful behavior can be developed there first, then extracted into Eliash
when experience shows what is reusable. The notebook should not have to wait for
a complete curator framework.

**This repository currently contains a first concept, not an implemented backend.**
Technology, deployment and interface choices remain open.
